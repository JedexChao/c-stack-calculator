# C 语言栈计算器（中缀表达式）

基于 **C 语言栈（Stack）** 与 **中缀表达式（Infix Expression）** 知识实现的简易加减乘除计算器，界面仅用 `printf` 打印 ASCII 面板，不依赖任何图形库。

## 功能

- 支持四则运算：`+` `-` `*` `/`
- 支持括号 `( )`、小数、一元负号（如 `-3 + 2`、`2 * (-4 + 1)`）
- 表达式求值采用调度场算法（Shunting-yard）思想：边扫描中缀表达式，边用**运算符栈**和**操作数栈**按优先级计算
- 异常处理：括号不匹配、非法字符、除数为 0、操作数个数异常

## 算法说明

1. **运算符栈** `op_stack`：存放 `+ - * / ( )`；**操作数栈** `num_stack`：存放扫描到的数字。
2. 从左到右扫描表达式：
   - 遇到数字 → 直接压入操作数栈；
   - 遇到 `(` → 压入运算符栈；
   - 遇到 `)` → 不断弹出运算符并计算，直到遇到 `(`；
   - 遇到运算符 → 当栈顶运算符优先级 **不低于** 当前运算符时，先弹出栈顶运算符计算，再压入当前运算符；
   - 扫描结束后清空运算符栈，最终操作数栈顶即为结果。
3. 优先级：`* /` > `+ -`。

## 目录结构

```
.
├── calculator.c   // 主程序：栈实现 + 中缀表达式求值 + printf 界面
├── Makefile       // 编译脚本
└── README.md
```

## 编译与运行

### Linux / macOS（gcc）

```bash
gcc -std=c11 -Wall -Wextra -o calculator calculator.c
./calculator
```

或使用 Makefile：

```bash
make
./calculator
```

### Windows（MinGW / MSYS2）

```bash
gcc -std=c11 -Wall -Wextra -o calculator.exe calculator.c
calculator.exe
```

## 运行示例

```
  +------------------------------------------+
  |      C Stack Infix Calculator           |
  +------------------------------------------+
  |  Expression : (12 + 3) * 4 / 2           |
  |  Result     : 30                        |
  +------------------------------------------+

  Enter expression >
```

支持的输入示例：

```
1 + 2 * 3
(12 + 3) * 4 / 2
-3.5 + 2 * (-1 + 5)
```

输入 `q` 或 `Q` 退出程序。
